# `--env EDGECLAW_HTTPS_TIMEOUT_MS=1500` → 上游任务以 ERROR 收场 (走真实失败路径)。

#           send_llm=0), 只有重启 + /task resume 能人工救回;
#   改动后: `second` 被扫描启动 → 跑完 → COMPLETED。
