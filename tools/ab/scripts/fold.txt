# 为什么不再靠阈值自己触发：触发判据现在只有 token 轴（组的上下文 > context_window
# - 16384），而夹具的语料只有几十个 token；窗口是 1M（config.json 的默认值），所以
# 自动路径**永远不会**在夹具里过线。要造"自动折"的夹具得塞进 ~1M token 的会话，不划算。
# 自动触发（两个挂载点 / 扫描 / 失败闸门）由单测覆盖：
#   tests/test_group_fold.c 的 test_fold_before_request / test_fold_on_non_settling_advance
#   / test_try_scans_all_sessions / test_fold_failure_cap，判据本身还有两侧的边界断言。
# 手动入口与自动入口共用同一条 start → 屏障 → prompt → 落地路径（tests/test_commands_group_fold.c）。
#
# 这一步要证的：折叠的**产物**（group memory 文本 / 折叠水位 / session.json 结构）
# 与新 prompt 布局逐字节可比，且盘上不会多出系统组或折叠任务。
